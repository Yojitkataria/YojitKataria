## 🔭 Featured Project

### [telecom-bss-platform](https://github.com/Yojitkataria/telecom-bss-platform)
Personal portfolio project: a subscription and billing platform with customer onboarding and KYC, plan catalog, subscription lifecycle, usage, invoicing and payments.

- 🧱 **Modular monolith** in Spring Boot 3 (Java 21), designed to be split into microservices
- 🔐 **JWT + role-based security** (Spring Security 6), BCrypt, secrets from the environment
- 🗄️ **MySQL with Flyway** versioned migrations
- ✅ **CI/CD on GitHub Actions**: build and tests against a MySQL container, AI-assisted PR review (Gemini), merge gate, protected `main`
- 🗺️ Roadmap: Docker, React UI, microservices split, SonarQube
